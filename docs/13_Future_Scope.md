# 13 — Future Scope

1. **Live GitHub / Resume Parser**: Automatically ingest a learner's GitHub repositories and resume to pre-populate skill proficiencies using AST code analysis and semantic vector embeddings.
2. **Interactive Coding Sandboxes**: Embed lightweight in-browser Python/SQL execution environments directly into diagnostic assessment checkpoints.
3. **Peer Study Cohorts & Mentorship Matchmaking**: Connect learners at similar DAG roadmap phases for collaborative milestone pair-programming.
4. **Real-time Job Market Integration**: Ingest live job postings from LinkedIn and Indeed via webhooks to update Career-Skill importance weights based on shifting market demand.
5. **Multi-Agent Coding Tutor**: Integrate specialized subagents for automated code review, test case generation, and mock technical interview simulations.
